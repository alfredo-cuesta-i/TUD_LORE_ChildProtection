# Context
This project is built around "children online protection".
It does not model the real world BUT a partially observable multi-agent ecosystem where actors interact, create events, derive observations, activate situations, perform interventions, and generate auditable outcome traces. In other words, the outcome is a History-derived fact.

# Task
1. Open and read all the markdown files in the `knowledge_base` folder.
2. DO NOT MAKE any changes in the files. You must use the `simulation.md` description and follow the specifications, rules and constraints given in the knowledge base, together with your reasoning capabilities, to undergo the tasks.
3. Build a new scenario on a new markdown file and leave it in the `knowledge_base/scenario` folder. The scenario must be detailed and traceable. For example, instead of "14 year old boy , etc" it should say `agent/ChildAgent - Demographics - Age - 14`.
4. Select two policies and compare their outcome on this ecosystem under the same scenario. To this end run a traceable simulation with both policies and produce. Traceable meand the same than above.
5. Find one gap in the knowledge base such that after bridgeing it the children online safety is stronger and reason why is that so.
