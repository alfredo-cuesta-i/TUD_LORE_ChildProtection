# LLM-based Ontology-driven Reproducible Environment <br> _Child Online Protection_
> REPO `TUD_LORE_ChildProtection`

**Could we build a Multi-Agent Policy Evaluation Environment for Child Online Protection?**

The idea would NOT be to simulate reality, because we have no reliable way to evaluate whether such a simulation is faithful to real children, parents, teachers or offenders. 

INSTEAD, the goal would be to create a parameterizable and reproducible environment containing actors such as 
- Child, 
- Parent, 
- Teacher, 
- Platform, 
- Protection System, 
- Predator. 

So each actor would be defined by configurable behavioural parameters.

In other words, the contribution would be the environment itself: 
the infrastructure that allows researchers to study, compare and stress-test protection policies, intervention strategies and decision-making mechanisms under controlled conditions.
