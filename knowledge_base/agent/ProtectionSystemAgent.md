# Protection system 
## Description
Represents the intelligent protection layer operating within the ecosystem.
The Protection System is not the platform itself.
It may receive signals from:
- the platform
- parents
- teachers
- psychologists
- child reports
- external detection systems
The goal of the Protection System is:
- risk reduction
- child empowerment
- intervention selection
- uncertainty management
Unlike a detector, the Protection System decides which action should be taken after available evidence is considered.
