# Threat actor 
## Description
Represents an actor attempting to influence, manipulate, deceive, exploit, recruit, blackmail, radicalize, harass, or otherwise harm a child.
The objective is not to model criminal behaviour realistically.
The objective is to generate a diverse set of threat profiles that create different protection challenges for the ecosystem.
A threat actor may be:
- a single individual
- a coordinated group
- an automated system
- a fraudulent organization
- a peer
- an unknown online contact
