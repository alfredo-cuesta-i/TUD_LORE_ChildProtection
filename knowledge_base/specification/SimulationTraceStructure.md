# SimulationTraceStructure.md

## Purpose

Defines the complete output generated by a simulation run.

A simulation trace guarantees reproducibility.

Every run must produce a trace conforming to this structure.

## Simulation Trace Structure

```text
SimulationTrace
  simulation_id
  simulation_seed
  initial_agents
  event_sequence
  situation_sequence
  observation_sequence
  intervention_sequence
  final_outcomes
```

## Fields

### simulation_id

Unique simulation identifier.

Example:

```text
SIM-2026-001
```

### simulation_seed

Provides reproducibility for simulation execution.

The same:

- scenario
- agent configurations
- ontology files
- simulation seed

must produce the same simulation trace under a deterministic execution policy.

The seed is part of the trace and must always be recorded.

### initial_agents

Complete list of participating agents and their configurations.

### event_sequence

Chronological collection of Event structures.

Example:

```text
E1
E2
E3
...
```

### situation_sequence

Chronological collection of situations representing world evolution.

Examples:

```text
No relationship
New online friendship
Trust building
Dependency formation
```

### observation_sequence

Chronological collection of Observation structures.

### intervention_sequence

Chronological collection of Intervention structures.

### final_outcomes

One or more outcomes selected from OutcomeOntology.

Examples:

```text
Contact established
Parent involved
Educational intervention
Trust building reached
```



## Example

```text
SimulationTrace
  simulation_id: SIM-007
  initial_agents:
    Child
    ThreatActor
    ParentUnit
    Platform
    ProtectionSystem

  event_sequence:
    E1
    E2
    E3

  situation_sequence:
    Social isolation
    New online friendship
    Trust building

  observation_sequence:
    O1
    O2

  intervention_sequence:
    I1

  final_outcomes:
    Parent involved
    Educational intervention
    Contact terminated
```
