# EventAuthorityOntology.md

## Purpose

Defines which actors are allowed to generate which events.

An event generated by an unauthorized actor is invalid.

---

## Child

may generate:

- Friend request accepted
- Friend request rejected
- Conversation continued
- Personal information shared
- Name shared
- Age shared
- School shared
- Location shared
- Contact information shared
- Photo shared
- Video shared
- Live image shared
- Child report submitted
- Child seeks help
- Contact blocked
- Contact unblocked

---

## ThreatActor

may generate:

- Friend request sent
- New conversation started
- Conversation continued
- Personal information requested
- Compliment delivered
- Shared interest identified
- Emotional support offered
- Gift or reward offered
- Romantic interest expressed
- Trust-building conversation
- Dependency-building interaction
- Secrecy requested
- Emotional pressure applied
- Guilt induction applied
- Authority claim made
- Threat delivered
- Blackmail attempt
- Coercive request
